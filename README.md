A [make.fun](https://make.fun) bounty entry: a single warning label for a time machine, in 120 characters or fewer.

> WARNING: Do not kill your grandfather. He is the only one who knows how this machine works.

It reads like a genuine safety notice, turns the grandfather paradox into the joke instead of naming it flatly, and saves the twist for the last few words.

## Run it

```sh
python3 main.py
```

Writes the label to `/output/entry.txt` (91 characters, UTF-8, single line). The program is deterministic — no randomness, no network — and validates the label (1–120 characters, no control or invisible characters) before writing, then re-reads the file and re-verifies its hash.
